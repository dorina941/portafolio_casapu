Clases, encapsulación y más

Estos son los niveles base del juego. Cada concepto tiene teoría, código y una frase lista para entrevistas.

Nivel 1

Clases y Objetos

Clase = molde, objeto = instancia real en memoria.

Teoría clave

  • Clase = molde.
  • Objeto = instancia.
  • Una clase define estructura y comportamiento.

Qué pasa aquí

  • Persona define cómo es una persona.
  • p es una persona real en memoria.
  • p.saludar() ejecuta el método.

Frase entrevista: Una clase define estructura y comportamiento, un objeto es una instancia de esa clase.

Clase

// CLASE
class Persona {
    String nombre;
    int edad;

    void saludar() {
        System.out.println("Hola, me llamo " + nombre);
    }
}

Crear objeto

public class Main {
    public static void main(String[] args) {
        Persona p = new Persona();
        p.nombre = "Juan";
        p.edad = 30;

        p.saludar();
    }
}
Nivel 2

Encapsulación

Protege datos y controla el acceso.

Qué pasa aquí

  • private protege la variable.
  • Solo se accede con métodos controlados.
  • Evita estados inválidos.

Frase entrevista: Encapsulación controla el acceso a los datos y evita estados inválidos.

Mal (datos expuestos)

class Persona {
    public int edad;
}

Bien (encapsulado)

class Persona {
    private int edad;

    public int getEdad() {
        return edad;
    }

    public void setEdad(int edad) {
        if (edad > 0) {
            this.edad = edad;
        }
    }
}
Nivel 3

Herencia

Reutiliza comportamiento común.

Qué pasa aquí

  • Perro hereda métodos de Animal.
  • No repites código.

Frase entrevista: La herencia permite reutilizar comportamiento común.

Ejemplo

class Animal {
    void comer() {
        System.out.println("El animal come");
    }
}

class Perro extends Animal {
    void ladrar() {
        System.out.println("Guau");
    }
}

Perro p = new Perro();
p.comer();
p.ladrar();
Nivel 4

Polimorfismo

El método ejecutado depende del objeto real.

Qué pasó

  • El tipo es Animal.
  • El comportamiento es de Perro.
  • Se decide en tiempo de ejecución.

Frase entrevista: El método que se ejecuta depende del objeto real, no de la referencia.

Salida: Guau

Ejemplo

class Animal {
    void sonido() {
        System.out.println("Sonido genérico");
    }
}

class Perro extends Animal {
    void sonido() {
        System.out.println("Guau");
    }
}

Animal a = new Perro();
a.sonido();
Nivel 5

Abstracción

Las interfaces definen contratos.

Qué pasa aquí

  • La interfaz dice qué hacer.
  • La clase decide cómo hacerlo.

Frase entrevista: Las interfaces definen contratos.

Interface

interface Vehiculo {
    void arrancar();
}

class Coche implements Vehiculo {
    public void arrancar() {
        System.out.println("Coche arrancando");
    }
}
Nivel 6

Colecciones

List, Set y Map para datos y búsquedas eficientes.

Qué pasa aquí

  • List mantiene orden y permite duplicados.
  • Set elimina repetidos automáticamente.
  • Map guarda clave y valor para acceso rápido.

Frase entrevista: Map se usa para búsquedas eficientes por clave.

List

List<String> nombres = new ArrayList<>();
nombres.add("Ana");
nombres.add("Juan");
nombres.add("Ana");

System.out.println(nombres.get(0));

Set

Set<String> nombres = new HashSet<>();
nombres.add("Ana");
nombres.add("Juan");
nombres.add("Ana");

System.out.println(nombres.size()); // 2

Map

Map<Integer, String> usuarios = new HashMap<>();
usuarios.put(1, "Juan");
usuarios.put(2, "Ana");

System.out.println(usuarios.get(1));
Nivel 7

Excepciones

Maneja errores con try, catch y finally.

Qué pasa aquí

  • catch maneja el error.
  • finally se ejecuta siempre.

Ejemplo

try {
    int x = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Error: división por cero");
} finally {
    System.out.println("Siempre se ejecuta");
}
Nivel 8

Stack vs Heap

Variables locales vs objetos en memoria.

Qué pasa aquí

  • Stack -> variables locales, rápido y por hilo.
  • Heap -> objetos, memoria compartida.

Frase entrevista: El Stack es por hilo, el Heap es compartido.

Ejemplo

void metodo() {
    int x = 10;          // STACK
    Persona p = new Persona(); // HEAP
}
Nivel 9

Concurrencia

Separar lógica y ejecución de hilos.

Qué pasa aquí

  • Runnable separa la lógica del hilo.
  • start() inicia la ejecución.

Frase entrevista: Runnable permite desacoplar la tarea del hilo que la ejecuta.

Ejemplo

class MiHilo implements Runnable {
    public void run() {
        System.out.println("Ejecutando hilo");
    }
}

Thread t = new Thread(new MiHilo());
t.start();

Logica del juego

El motor controla progreso, puntaje y la transición entre niveles.

Game engine

class LearningGame {
  constructor(lessons) {
    this.lessons = lessons;
    this.currentLesson = 0;
    this.score = 0;
  }

  answer(correct) {
    if (correct) this.score += 10;
  }

  nextLesson() {
    this.currentLesson++;
  }
}

Aplicando conceptos dentro del juego

  • Clases y objetos: Lesson, Challenge, Game.
  • Encapsulación: el jugador no manipula puntaje ni nivel.
  • Herencia: retos especializados heredan de un reto base.
  • Polimorfismo: challenge.checkAnswer(userInput).
  • Abstracción: Challenge define el contrato.
  • Colecciones: arrays, sets y maps para contenido y progreso.
